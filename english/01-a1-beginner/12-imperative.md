# Imperativo (*Imperative*)

## Objetivo

Ao final deste tópico, o estudante será capaz de usar o modo imperativo em inglês para dar ordens, instruções, avisos, conselhos e convites.

## Pré-requisitos

- [Verbo *To Be*](01-verb-to-be.md)
- [Simple Present](04-simple-present.md)

## Conceitos Fundamentais

### O que é o Imperativo?

O imperativo é usado para dar **ordens, instruções, conselhos ou convites** diretamente a alguém. É a forma mais simples do inglês — usa o verbo na **forma base**, sem sujeito.

### Estrutura

| Forma | Estrutura | Exemplo | Tradução |
|-------|----------|---------|----------|
| Afirmativa | **Verbo (base) + complemento** | Sit down. | Sente-se. |
| Negativa | **Don't + verbo (base) + complemento** | Don't sit there. | Não sente aí. |

> O sujeito (*you*) está **implícito** — não precisa ser dito.

### Imperativo Afirmativo

```
Open the door.           → Abra a porta.
Sit down, please.        → Sente-se, por favor.
Listen carefully.        → Ouça com atenção.
Turn left at the corner. → Vire à esquerda na esquina.
Come here!               → Venha aqui!
Wait a moment.           → Espere um momento.
Help me!                 → Me ajude!
Be quiet!                → Fique quieto!
Be careful!              → Tenha cuidado!
Have a seat.             → Sente-se. (educado)
```

### Imperativo Negativo

Estrutura: **Don't + verbo (base)**

```
Don't open the window.    → Não abra a janela.
Don't be late!            → Não se atrase!
Don't worry.              → Não se preocupe.
Don't touch that!         → Não toque nisso!
Don't forget your keys.   → Não esqueça suas chaves.
Don't run in the hallway. → Não corra no corredor.
Don't be afraid.          → Não tenha medo.
```

### Usos do Imperativo

| Uso | Exemplo | Tom |
|-----|---------|-----|
| **Ordem** | Stop! / Sit down! | Direto, autoritário |
| **Instrução** | Turn right, then go straight. | Neutro, informativo |
| **Aviso** | Be careful! / Watch out! | Urgente |
| **Conselho** | Take an umbrella. / Get some rest. | Amigável |
| **Convite** | Come in! / Have a seat! | Acolhedor |
| **Pedido** | Pass me the salt, please. | Educado (com *please*) |
| **Encorajamento** | Don't give up! / Keep going! | Motivacional |

### Suavizando o Imperativo

O imperativo pode soar rude. Para suavizá-lo:

| Estratégia | Exemplo | Tom |
|-----------|---------|-----|
| Adicionar **please** | Close the door, **please**. | Educado |
| Usar **let's** (vamos) | **Let's** go! / **Let's** eat! | Inclusivo |
| Usar **could you** | **Could you** close the door? | Mais educado (não é imperativo) |
| Usar **do** (ênfase positiva) | **Do** sit down! / **Do** come in! | Enfático e acolhedor |

### *Let's* — Imperativo Inclusivo

*Let's* (= let us) inclui o falante na ação. É uma sugestão para "nós":

```
Let's go to the movies!       → Vamos ao cinema!
Let's eat!                    → Vamos comer!
Let's not argue.              → Não vamos discutir.
Let's study together.         → Vamos estudar juntos.
```

> **Negativa de *let's***: *Let's **not*** + verbo:
> - *Let's **not** be late.* → Não vamos nos atrasar.

## Regras e Exceções

### Imperativo com *be*

O verbo *be* também pode ser usado no imperativo:

```
Be quiet!         → Fique quieto!
Be careful!       → Cuidado!
Be patient.       → Tenha paciência.
Be nice to her.   → Seja gentil com ela.
Don't be silly!   → Não seja bobo!
Don't be afraid.  → Não tenha medo.
```

### Imperativo com *never*

*Never* pode substituir *don't* para ênfase:

```
Never give up!              → Nunca desista!
Never touch that button!    → Nunca toque naquele botão!
Never forget your password. → Nunca esqueça sua senha.
```

### Imperativo em placas e avisos

| Placa | Significado |
|-------|------------|
| **PUSH** | Empurre |
| **PULL** | Puxe |
| **KEEP OUT** | Não entre / Mantenha-se afastado |
| **DO NOT ENTER** | Não entre |
| **NO SMOKING** | Proibido fumar |
| **KEEP OFF THE GRASS** | Não pise na grama |
| **CAUTION: WET FLOOR** | Cuidado: chão molhado |

### Imperativo em receitas e instruções

```
1. Preheat the oven to 180°C.
2. Mix the flour and sugar in a bowl.
3. Add the eggs and milk.
4. Stir well.
5. Pour the mixture into a baking pan.
6. Bake for 30 minutes.
7. Let it cool before serving.
```

## Erros Comuns

### 1. Adicionar sujeito *you*

- ❌ *You sit down!* (soa estranho ou agressivo)
- ✅ *Sit down!*

> *You* pode ser usado para ênfase ou irritação: *"**You** be quiet!"*, mas é raro.

### 2. Usar *to* antes do verbo

- ❌ *To open the door.*
- ✅ *Open the door.*

### 3. Usar *doesn't* na negativa

- ❌ *Doesn't open the door.*
- ✅ ***Don't** open the door.*

### 4. Esquecer *don't* com *be*

- ❌ *Not be late!*
- ✅ ***Don't** be late!*

### 5. Confundir imperativo com pergunta

- ❌ *Do you sit down?* (pergunta)
- ✅ *Sit down.* (imperativo)
- ✅ *Can you sit down?* (pedido educado)

## Exemplos

### Diálogo — Instruções de GPS

```
A: How do I get to the hospital?
B: Go straight on this street. Turn right at the traffic light.
   Then go past the supermarket and turn left.
   The hospital is on your right. Don't miss the sign!
A: Got it. Thanks!
B: You're welcome. Drive carefully!
```

### Diálogo — Em sala de aula

```
Teacher: Good morning, everyone! Please sit down.
         Open your books to page 42.
         Don't forget to bring your homework tomorrow.
         Let's start with the reading exercise.
Students: OK!
Teacher: Read the text quietly. Don't talk to your neighbor.
         Be ready to answer questions in 5 minutes.
```

### Situações do dia a dia

```
Don't worry, everything will be OK.
Help yourself! (Sirva-se!)
Have a nice day!
Take care!
Call me when you arrive.
Don't forget to lock the door.
Let's take a break.
```
