# Só Resta Estudar

Repositório dedicado ao estudo de tecnologias, frameworks, linguagens de programação e tudo relacionado a desenvolvimento de software — com foco em boas práticas, arquitetura de software, sistemas distribuídos, Clean Architecture, DDD, SOLID, POO, Programação Funcional e mais.

---

## Estrutura do Repositório

```
├── AGENTS.md              # Regras e convenções do agente de pesquisa
├── README.md              # Este arquivo
├── roadmap.md             # Índice global de todos os assuntos
├── progress.md            # Progresso de estudo por tópico
├── glossary.md            # Glossário de termos técnicos
├── distributed-systems/   # Sistemas Distribuídos
└── ...                    # Novos assuntos serão adicionados aqui
```

## Como Navegar

- Consulte o [roadmap.md](roadmap.md) para a visão geral e ordem de estudo recomendada.
